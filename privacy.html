몽글 놀이터 놀이터로 돌아가기

개인정보 처리방침

최종 업데이트: 2026년 7월 29일 · 적용 버전 1.0.0

핵심 요약. 몽글 놀이터는 회원가입이 없습니다. 아이의 이름·사진·음성·위치를 수집하지 않고, 광고나 분석 추적을 넣지 않으며, 놀이 기록은 아이가 사용하는 기기의 브라우저 저장소에만 남습니다.

1. 수집하지 않는 정보

  • 이름, 생년월일, 전화번호, 이메일 등 계정 정보
  • 사진, 동영상, 마이크 음성
  • 위치 정보와 기기 고유 식별자
  • 광고 식별자, 제3자 분석 도구의 행동 기록

2. 기기에만 저장되는 정보

아래 항목은 브라우저의 localStorage에 저장되며 외부 서버로 전송되지 않습니다. 보호자가 직접 삭제하거나 브라우저 저장 데이터를 지우면 함께 사라집니다.

항목 쓰임
보호자가 입력한 애칭 화면에서 아이를 부르는 호칭 표시
놀이 완료·정답·도움 횟수 오늘의 추천 놀이와 난이도 자동 조정
보호자 관찰 기록(최대 3건) 다음 놀이 난이도 보정
소리·음악·놀이 시간 설정 다음 실행 시 같은 설정 유지

3. 네트워크 통신

앱은 실행에 필요한 화면·이미지·음성 파일을 배포 서버(GitHub Pages)에서 받아옵니다. 이 과정에서 표준 웹 요청 기록이 호스팅 사업자 측에 남을 수 있습니다. 그 외에 아이가 만든 그림, 놀이 기록, 애칭을 외부로 보내는 통신은 없습니다. 음성 안내는 미리 생성된 파일을 재생하며, 실행 중 외부 음성 API로 문장을 전송하지 않습니다.

4. 오프라인 저장

설치형(PWA) 사용을 위해 서비스 워커가 화면과 음성 파일을 기기 캐시에 저장합니다. 보호자가 선택한 경우에만 약 40MB의 전체 음성팩을 추가로 내려받고, 보호자 공간에서 언제든 삭제할 수 있습니다.

5. 아동 보호

이 앱은 만 3~5세 아동과 보호자가 함께 사용하도록 설계되었습니다. 아동에게 광고를 보여주지 않고, 외부 링크나 채팅·소셜 기능, 인앱 결제를 넣지 않았습니다. 보호자 전용 화면은 간단한 숫자 확인 절차 뒤에 열립니다.

6. 보호자의 권리

  • 보호자 공간 > 데이터 관리에서 이 앱의 로컬 기록·설정을 두 단계 확인 후 한 번에 삭제할 수 있습니다.
  • 기록 이동 기능으로 로컬 JSON 파일로 백업하고 다른 기기에서 복원할 수 있습니다.
  • 브라우저 설정에서 사이트 데이터를 삭제하면 모든 기록이 즉시 사라집니다.

7. 문의

개인정보 관련 문의는 GitHub 이슈로 남겨 주세요. 문의 시 아이의 개인정보를 포함하지 말아 주세요.

8. 방침 변경

내용이 바뀌면 이 페이지의 최종 업데이트 날짜를 갱신합니다. 중요한 변경은 앱 첫 화면에서 함께 안내합니다.
