몽글 놀이터 놀이터로 돌아가기

문의와 도움말

자주 묻는 질문과 문제 해결 방법을 모았습니다.

홈 화면에 설치하기

  • 안드로이드 Chrome: 주소창 오른쪽 메뉴 > “앱 설치” 또는 “홈 화면에 추가”
  • 아이폰 Safari: 공유 버튼 > “홈 화면에 추가”

설치하면 전체 화면으로 열리고, 한 번 실행한 뒤에는 인터넷 없이도 놀이를 이어갈 수 있습니다.

소리가 나오지 않을 때

  • 기기의 무음 모드와 볼륨을 확인해 주세요.
  • 화면 위쪽의 말소리와 음악 토글이 켜져 있는지 확인해 주세요.
  • iOS는 첫 터치 이후에 소리가 재생됩니다. 아무 버튼이나 한 번 눌러 주세요.
  • 보호자 공간의 음성 점검 버튼으로 F1 음성을 직접 확인할 수 있습니다.

오프라인에서 음성이 끊길 때

기본 설치에는 화면과 점검용 음성만 포함됩니다. 보호자 공간에서 전체 음성팩(약 40MB)을 내려받으면 모든 문장을 오프라인에서 재생할 수 있고, 필요 없을 때 삭제할 수 있습니다. 정적 음원에 문제가 있으면 기기의 한국어 음성 엔진으로 자동 대체됩니다.

기록을 옮기거나 지우고 싶을 때

  • 보호자 공간 > 기록 이동에서 JSON 파일로 백업하고 새 기기에서 복원합니다.
  • 보호자 공간 > 데이터 관리에서 두 단계 확인 후 모든 로컬 기록과 설정을 삭제합니다.
  • 시크릿(비공개) 모드에서는 창을 닫으면 기록이 남지 않습니다.

업데이트가 반영되지 않을 때

설치형 앱은 오프라인 캐시를 사용합니다. 새 버전이 보이지 않으면 앱을 완전히 종료한 뒤 다시 열어 주세요. 그래도 같으면 브라우저에서 페이지를 새로 고침해 주세요.

문의하기

버그 제보와 제안은 GitHub 이슈로 보내 주세요. 보호자 공간의 문제 해결 정보 복사 기능을 사용하면 버전·접속·소리·저장 상태만 담긴 요약을 붙여 넣을 수 있습니다. 이 요약에는 애칭과 놀이 기록이 포함되지 않습니다.
